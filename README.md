## 🎮 How to Play

1. Run the program.
2. A random word is selected from `words.txt`.
3. The word is displayed using `_`.
4. Enter one letter at a time.
5. Correct letters are revealed.
6. Wrong guesses reduce your attempts.
7. Previously guessed letters cannot be used again.
8. You have **7 attempts** to guess the word.
9. Reveal the complete word to win.

## ▶️ How to Run

Compile the program using a C++ compiler:

```bash
g++ main.cpp -o Hangman
```

Then run:

```bash
Hangman
```

Make sure `words.txt` is in the same directory as the program.
